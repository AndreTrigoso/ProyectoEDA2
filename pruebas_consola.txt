0. COMPILACION Y EJECUCION EN WINDOWS (PowerShell)
--------------------------------------------------------------------------------
Ubicarse en la carpeta del proyecto (donde esta HIV2_ALL_2021_env_DNA.2000.fasta)
y compilar el motor C++ ejecutando:

    .\build.bat

Luego iniciar la interfaz de consola en C++ con:

    .\genomic_engine.exe

Nota: cada caso de prueba describe las entradas exactas que debes escribir en
el menu interactivo (una por linea, presionando Enter) y la salida esperada real.

foreach ($p in $pruebas) {
    $salida = ($p.Input | .\genomic_engine.exe) -join "`n"
    $rc = $LASTEXITCODE
    $ok = ($rc -eq 0)
    foreach ($c in $p.Checks) {
        if (-not $salida.Contains($c)) {
            $ok = $false
            Write-Host "[FALLO] $($p.Nombre): no se encontro '$c'" -ForegroundColor Red
        }
    }
    if ($ok) {
        Write-Host "[OK] $($p.Nombre) (exit=$rc)" -ForegroundColor Green
    } else {
        Write-Host "[ERROR] $($p.Nombre) (exit=$rc)" -ForegroundColor Red
    }
}
